## Logboek
This objecttype was created for [ITA](https://ita.readthedocs.io/). ITA stores information about activities surrounding the processing of a Contactverzoek in a Activity Log. While still researching what would be the proper common ground standard for this information, we created an Objecttype to store this information. 
Some properties are not reflected in the JSON-schema and are shown below.

- Scope: public
- Version: 1.0
- Created: 2025-07-10
- Modified: 2025-07-10
- Status: Proposed
